# gst_calculator

Free GST Calculator is a simple and easy-to-use online tool that helps users quickly calculate GST amounts. It supports both **GST Inclusive** and **GST Exclusive** calculations, allowing users to find the GST amount, original/base amount, and final total amount easily. Users can enter an amount, select the required GST rate, and choose whether the amount is inclusive or exclusive of GST. This calculator is designed to make GST calculations fast, accurate, and convenient for everyday use.
